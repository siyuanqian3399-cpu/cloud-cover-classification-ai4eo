# cloud-cover-classification-ai4eo
The classification of cloud 
# Project Overview
Clouds are a major source of uncertainty in optical satellite imagery, as they block the observation of the Earth's surface. This limits the effectiveness of many Earth Observation applications such as land cover mapping, vegetation monitoring, and environmental analysis.

The aim of this project is to develop a simple and efficient method to detect cloud-covered pixels in Sentinel-2 imagery using spectral features and machine learning techniques.
